# ArtDock brand set

Two marks on the shipped icon's geometry, with the glass treatment: **Acrylic** (dark, the
app icon) and **Paper** (light, for light surfaces). Everything raster here is generated by
`tools/make-brand.py`, which lays each size out on its own pixel grid the way
`tools/make-icon.py` does; the lockups are the SVGs rendered at 2×.

| Folder | What | Use |
| --- | --- | --- |
| `windows/ArtDock.ico` | Acrylic, 16 20 24 32 40 48 64 128 256 | `ApplicationIcon` in the csproj, the tray, the installer |
| `windows/ArtDock-light.ico` | Paper, same frames | anywhere the icon sits on white |
| `png/acrylic-*.png`, `png/paper-*.png` | 16 to 1024 | Store listing, GitHub social image, docs |
| `web/favicon.ico` | Acrylic 16 32 48 | legacy `<link rel="icon">` |
| `web/favicon.svg` | Acrylic, vector | modern favicon, crisp at any size |
| `web/mark-light.svg` | Paper, vector | light-theme pages |
| `web/apple-touch-icon.png` | 180, square ground | iOS rounds the corners itself |
| `web/icon-192.png`, `web/icon-512.png` | PWA icons | referenced by `site.webmanifest` |
| `web/icon-maskable-512.png` | mark at 82% on a full ground | Android adaptive icon |
| `web/site.webmanifest`, `web/head.html` | manifest and the `<head>` lines | paste `head.html` into the site's `<head>`; the manifest expects the icons at the site root |
| `lockups/lockup-stacked-dark.svg` + `@2x.png` | Acrylic mark, wordmark, "A DOCK FOR WINDOWS 11", on `#1b1e2b` | README header, release page |
| `lockups/lockup-stacked-transparent.svg` + `@2x.png` | same, no ground | for placing on any dark surface |
| `lockups/lockup-light.svg` + `@2x.png` | Paper mark beside the wordmark on `#f6f7fb` | website header |
| `lockups/lockup-light-transparent.svg` + `@2x.png` | same, no ground | for placing on any light surface |
| `installer/splash.png` | the dark stacked lockup at 480×390, 1× | the setup's splash, passed to `vpk` by `tools/release.ps1`; the setup scales it to the display and runs its progress bar, `#4d5cff`, along the bottom |

The lockup SVGs embed the Manrope latin subset (OFL) so they render the same everywhere.

Colours: ground `#1f2333 → #14161f` (Acrylic) or `#f6f7fc → #e4e7f2` (Paper); magnified
pill `#8c99ff → #4d5cff`; resting pills `#e6e9ff` (Acrylic) or `#3a3f58` (Paper).

Regenerate the marks with:

```
python tools/make-brand.py brand
```

That also remakes `installer/splash.png` from `lockups/lockup-stacked-dark@2x.png`, so a
changed lockup reaches the setup by rerunning it.

The shipped `src/ArtDock/Assets/ArtDock.ico` is a copy of `windows/ArtDock.ico`, the Acrylic
mark, since 2026-09-28. Regenerating does not update it: copy the new one over it and
rebuild.
